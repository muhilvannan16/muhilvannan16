## Selected Work

**Space Station RPG (Mobile)**
Android port of a terminal survival RPG built with Kivy — procedural map generation, multi-phase boss encounters, full save/load persistence, and a GitHub Actions pipeline producing signed debug APKs.
[Repository](https://github.com/muhilvannan16/space-station-rpg-mobile)

**NoteForge**
An AI-assisted study app with notes, flashcards, quizzes, and spaced repetition (SM-2 algorithm), plus voice-to-text via Groq's Whisper API. Ships as both a desktop app (CustomTkinter) and a multi-user web app (Streamlit).
[Repository](https://github.com/muhilvannan16/NoteForge)

**GitHub Repo Analyzer**
Full-stack tool that scores any public repo's health from 0–100 using real commit activity, issue responsiveness, and project hygiene. FastAPI backend, vanilla JS frontend, Dockerized, deployed with CI/CD.
[Live](https://repo-analyzer-ts4d.onrender.com) | [Repository](https://github.com/muhilvannan16/Repo-Analyzer)

**pygamelogic / pygamesense**
Two published PyPI packages: a lightweight game logic library (inventory, items, cooldowns) and an event-driven hazard/game-sense engine for text-based games.
[pygamelogic](https://pypi.org/project/pygamelogic/) | [pygamesense](https://pypi.org/project/pygamesense/)
